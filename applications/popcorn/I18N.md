# Portal translations

All interface text is in `src/lib/assets/i18n/en.json` and `et.json`.
English is the fallback. To add a language, copy `en.json` to a valid locale
filename such as `fi.json`, translate its values, and set `_meta.name`.
Keep keys and placeholders such as `{count}` unchanged. Missing keys use English.
Rebuild and restart Popcorn: Vite discovers the JSON files at build time.
The language selector and locale routes need no manually maintained list.

Movie descriptions, titles, genres and credits come from TMDB, not these files.
Personal notes, folder names and other user-authored text are not translated.
